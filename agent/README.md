# PC 자동 동기화 (윈도우)

정해 둔 폴더의 채용현황 엑셀을 현황판 서버로 자동으로 보내는 프로그램입니다. 별도 설치 파일 없이 윈도우 기본 기능(PowerShell, 작업 스케줄러)만 씁니다.

## 설치

1. [저장소 zip 파일](https://github.com/seonhye061vv/-/archive/refs/heads/main.zip)을 내려받아 압축을 풀고, 그 안의 `agent` 폴더를 PC의 고정된 위치에 둡니다. 예: `C:\RecruitBoard\agent` (경로에 한글이 없는 곳을 권장합니다)
2. **`설치.bat`** 을 더블클릭합니다. 'Windows의 PC 보호' 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
3. 차례로 입력합니다.
   - 엑셀을 저장하는 폴더
   - 현황판 주소 (예: `https://recruit-board.vercel.app`)
   - 동기화 키 (Vercel 환경 변수 `SYNC_KEY` 값)

설치하면 바로 한 번 동기화하고, 이후 PC가 켜져 있는 동안 5분마다 확인합니다. 확인 주기는 현황판 관리자 화면의 'PC 자동 동기화' 탭에서 바꿀 수 있습니다.

## 사용

- 폴더에 엑셀을 **저장하기만** 하면 됩니다. 폴더에 엑셀이 여러 개면 가장 최근에 저장한 파일 하나를 보냅니다.
- 파일이 바뀌지 않았으면 서버는 '정상 확인 시각'만 갱신합니다.
- 오류가 있는 파일은 반영하지 않고 기존 데이터를 유지합니다. 오류 위치는 관리자 화면 '반영 기록'과 이 폴더의 `sync.log` 에 남습니다.
- 공고명이나 조직이 바뀐 파일은 자동으로 반영하지 않고 관리자 화면 '엑셀 반영' 탭에서 확인을 기다립니다.
- 바로 보내고 싶으면 **`지금 동기화.bat`** 을 실행합니다.

## 알아둘 점

- PC가 꺼져 있거나 잠자기 상태면 그동안은 반영되지 않습니다. 현황판은 마지막 데이터를 보여 주고 최신성 경고를 띄웁니다.
- 동기화 키는 이 PC의 현재 윈도우 사용자만 풀 수 있게 암호화해 `config.json` 에 저장합니다.
- 제거하려면 **`제거.bat`** 을 실행합니다.
