# 채용현황판 (MVP 미리보기)

현업 담당자가 채용 공고별 진행 단계를 직접 확인할 수 있게 하는 채용현황판의 첫 미리보기입니다. `index.html` 한 파일로 동작합니다.

- **관리자 화면**: 현황판, 엑셀 업로드·검증, 공고별 열람 권한(코드-계정 연결, 승인·회수), 반영 기록
- **현업 화면** (`#viewer`): 계정 ID로 로그인하면 본인에게 승인된 공고만 표시

## 알아둘 점

- 처음 열면 PRD에 적힌 공고 9건을 바탕으로 한 **예시 데이터**가 보입니다. 실제 채용 데이터는 이 저장소에 포함되어 있지 않습니다.
- 업로드한 엑셀과 권한 설정은 **그 브라우저에만** 저장되며 서버로 전송되지 않습니다. 다른 사람의 PC에서는 보이지 않습니다.
- 로그인은 데모용입니다. 실제 로그인, 서버의 공고별 권한 검사, 엑셀 자동 동기화는 사내 서버 구축 후 구현해야 합니다.
