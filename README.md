# 채용현황판 (MVP 미리보기)

현업 담당자가 채용 공고별 진행 단계를 직접 확인할 수 있게 하는 채용현황판의 첫 미리보기입니다. 빌드 과정이 없는 정적 웹사이트라서 Vercel에 그대로 배포할 수 있습니다.

## 화면

- `/` 관리자 화면: 현황판, 엑셀 업로드·검증, 공고별 열람 권한(코드-계정 연결, 승인·회수), 반영 기록
- `/viewer` 현업 화면: 계정 ID로 로그인하면 본인에게 승인된 공고만 표시

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `assets/style.css` | 화면 스타일 |
| `assets/app.js` | 엑셀 읽기·검증, 현황판, 권한 기능 |
| `vercel.json` | Vercel 설정 (`/viewer` 주소, 보안 헤더, 검색 노출 차단) |

## Vercel 배포

1. https://vercel.com/new 에서 GitHub로 로그인합니다.
2. 이 저장소를 **Import** 합니다.
3. Framework Preset은 **Other**, Build Command와 Output Directory는 비워 둔 채 **Deploy** 를 누릅니다.

이후 `main` 브랜치에 올라가는 변경은 Vercel이 자동으로 다시 배포합니다.

## 알아둘 점

- 처음 열면 PRD에 적힌 공고 9건을 바탕으로 한 **예시 데이터**가 보입니다. 실제 채용 데이터는 이 저장소에 포함되어 있지 않습니다.
- 업로드한 엑셀과 권한 설정은 **그 브라우저에만** 저장되며 서버로 전송되지 않습니다. 다른 사람의 PC에서는 보이지 않습니다.
- 로그인은 데모용입니다. 실제 로그인, 서버의 공고별 권한 검사, 엑셀 자동 동기화는 사내 서버(또는 Vercel 서버 기능과 사내 로그인 연동) 구축 후 구현해야 합니다.
